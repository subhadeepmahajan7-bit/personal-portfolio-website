# Personal Portfolio Website

## Summer Project 2026

### Project Overview
A personal portfolio website developed to showcase my academic background, technical skills, projects, certifications, and achievements.

### Objectives
- Build a professional online portfolio.
- Showcase technical skills and projects.
- Display academic achievements and certifications.
- Provide links to professional profiles.

### Technologies Used
- HTML
- CSS
- JavaScript
- Java

### Features
- Responsive portfolio interface
- About Me section
- Technical Skills section
- Projects showcase
- Certificates section
- Contact information
- Background music
